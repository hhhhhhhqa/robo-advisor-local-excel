# Final release — v1.1.0

This repository distributes one final version of the local Excel portfolio tracker.

- Set up once on each computer and work independently in desktop Excel.
- Enter ETF purchases, sales and five-currency exchanges in the trade table.
- Show current cash at the top and editable Initial cash at B19:B23.
- Calculate holdings, cash, daily portfolio history, performance and charts automatically from cached data.
- Download new prices and FX rates only when the user chooses Update.
- Provide English setup instructions, a worked buy/sell/FX tutorial and a complete file reference.

The final release keeps the accepted Excel calculation behavior. Unrelated research pipelines, historical previews and superseded public releases have been removed.
