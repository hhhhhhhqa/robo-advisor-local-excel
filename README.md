# 本地 Excel 投资组合工具

下载到自己的电脑，在 Excel 中记录交易，双击更新结果。每份下载拥有独立的 Excel、行情缓存和备份，日常使用不需要 GitHub 账号，也不用上传个人数据。

支持 Windows 和 Mac 的桌面 Microsoft Excel。使用原有的 ETF 买卖、五币种换汇、现金与持仓估值、收益率、夏普比率、回撤、历史图表和时间滑块。Python 计算在本机运行，初始化会自动下载运行环境，无需手动安装 Python 或输入命令。

## 下载和首次使用

1. 点击 GitHub 页面上方的 **Code → Download ZIP**，或下载 [打包好的使用包](https://github.com/hhhhhhhqa/robo-advisor-local-excel/releases/latest)。把 ZIP **完整解压**到自己的文档文件夹，不要在压缩包内直接运行。
2. Windows 双击 **`1_Setup.cmd`**；Mac 双击 **`1_Setup.command`**。首次初始化需要联网，会在当前文件夹内下载 Python 和依赖。等待出现“初始化完成”。
3. 打开新生成的 **`Portfolio.xlsx`**。它是你的工作文件，初始为 10,000 USD、无交易，可自行修改。
4. 填写后保存并关闭 Excel。Windows 双击 **`2_Update.cmd`**；Mac 双击 **`2_Update.command`**。第一次更新会下载行情和汇率，可能需要几分钟。
5. 看到“更新完成”后，再打开 `Portfolio.xlsx` 查看结果。以后只需重复“修改、保存关闭、双击更新、重新打开”。

移动工具时，请移动整个文件夹。初始化环境含本机路径；移动后应重新运行 `1_Setup`。不要只把 `Portfolio.xlsx` 单独发给别人运行：请分发本仓库的原始 ZIP，让每个人各自初始化。

### Mac 首次打开

优先使用 Releases 中的使用包，包内保留启动文件的可执行权限。若系统提示无法验证开发者，可在确认下载来源后，按 macOS 提示允许打开。若提示“没有执行权限”，打开“终端”，输入 `chmod +x `（末尾有空格），把两个 `.command` 文件拖入终端窗口，再按回车。这只需要处理一次。

Windows 如显示下载文件提示，请在确认来源后按系统提示允许运行。公司电脑若由管理员限制脚本或软件安装，需要管理员允许，程序不会修改系统级执行策略。

## 如何填写 Dashboard

| 位置 | 内容 | 填写方式 |
| --- | --- | --- |
| B4:B8 | USD、JPY、EUR、AUD、CNY 初始现金 | 非负数；日元整数，其余币种最多两位小数；至少一项大于零 |
| E3 | 估值日期 | 留空表示已下载数据中的最新 ETF 交易日；也可输入存在收盘价的美国交易日期 |
| E4 | 年化无风险利率 | 例如 `0.04` 或 `4%`，表示 4% |
| E5 | Update ETF prices | `Yes` 下载更新；`No` 使用本地缓存 |
| E6 | Update FX rates | `Yes` 下载更新；`No` 使用本地缓存 |
| A27:F226 | 交易输入 | 按日期从早到晚填写，同一天按行顺序处理，最多 200 笔 |

输入表的六列分别是日期、操作、ETF、股数或金额、支付币种、换入币种。支持 19 只美国上市 ETF，名单见 `config/assets.json`。

| Date | Action | ETF | Shares / amount | Cash currency | To currency |
| --- | --- | --- | ---: | --- | --- |
| 2026-08-27 | Buy | SPY | 2 | USD | 留空 |
| 2026-08-28 | Sell | SPY | 1 | USD | 留空 |
| 2026-08-28 | Exchange | 留空 | 500 | USD | JPY |

`Buy` 和 `Sell` 的数量为正整数股数，换入币种留空；`Exchange` 的数量为换出币种的金额，ETF 留空，换入币种必须不同。不能超额买入、超额卖出或产生负现金。日期必须是 Excel 日期，建议输入 `2026-08-27` 后确认单元格识别为日期。

首次更新没有缓存时，即使 E5/E6 为 `No`，也会先下载一份初始数据。之后按两个开关分别更新。要查看新行情，把相应开关改为 `Yes`。ETF 行情下载不含当日尚未完成的美国交易日；汇率不含当日 UTC 数据。`No` 不会自动取得最新市场数据。

## 结果与历史查看

更新会在同一张 Dashboard 中生成持仓、现金余额、成交记录、逐日组合价值和风险收益指标。拖动图表上方的时间滑块，所选日期、图中标记和对应指标会同步变化。持仓及币种余额表显示估值日结果，滑块改变的是历史指标和图中标记。

这是按日收盘价执行的模拟交易，不会向券商下单。ETF 使用 USD 收盘价；其他币种按当日或此前最近一期汇率折算，汇率最多可滞后 5 个自然日。收益和夏普基于每日组合 USD 价值，夏普使用 252 个交易日年化及 E4 的无风险利率；不足两个收益观察值或波动率为零时不提供夏普。计算不含分红、手续费和买卖价差，与原项目保持一致。

## 文件和个人数据

| 文件或文件夹 | 用途 |
| --- | --- |
| `Portfolio.xlsx` | 你自己的资金、交易和结果，初始化后生成 |
| `local_data/market/` | 本文件夹下载的 ETF 和汇率数据 |
| `local_data/backups/` | 更新前的 Excel，保留最近 5 份 |
| `local_data/last_update.log` | 更新日志，排查失败原因时使用 |
| `.tools/`、`.runtime/`、`.venv/` | 自动准备的本地运行环境 |
| `examples/excel/` | 原始模板及含 14 笔虚构交易的演示文件 |

运行环境和个人数据已列入 `.gitignore`。本工具不包含上传交易的功能；使用 uv/PyPI 下载运行环境、使用 Yahoo Finance 下载行情和汇率时需要联网。请把工作文件夹放在个人本地目录，避免让多人同时编辑同一份文件。

## 更新失败怎么办

程序会先校验输入并计算，再写入临时文件；成功后才替换 `Portfolio.xlsx`。输入错误、行情下载失败或计算失败时，不会把失败结果覆盖到你的 Excel 中。更新前还会保存备份。

| 提示或现象 | 处理方式 |
| --- | --- |
| Excel 仍在打开、文件无法写入 | 保存并关闭 `Portfolio.xlsx` 后重试 |
| 初始化或下载失败 | 检查网络能否访问 GitHub、astral.sh、PyPI 和 Yahoo Finance；重新运行对应入口 |
| `no ETF close` / `No ETF close` | 检查交易日或估值日，必要时把 E5 改为 `Yes` 后更新 |
| `insufficient ... cash/shares` | 现金或持仓不足，检查初始现金及此前交易 |
| `FX rate is stale` / `No ... FX rate` | 把 E6 改为 `Yes` 后更新，并确认日期在数据范围内 |
| 日期顺序错误 | 按交易日期从早到晚排列；同日交易按行顺序执行 |
| 重新下载或升级 | 解压到新文件夹并初始化，把旧的 `Portfolio.xlsx` 复制过来；不要用模板覆盖自己的工作文件 |

如需恢复，关闭 Excel，把 `local_data/backups/` 中相应版本复制到根目录并改名为 `Portfolio.xlsx`，再更新。不要删除唯一一份个人工作文件或备份。
