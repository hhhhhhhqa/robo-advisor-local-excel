Local Excel Portfolio Tracker — v1.1.0 Final Release

1. Extract the COMPLETE ZIP into a local folder you intend to keep.
2. Mac: double-click 1_Setup.command. Windows: double-click 1_Setup.cmd.
   Wait for "Setup completed". Setup installs software, not market data.
3. Open the generated Portfolio.xlsm in the main folder. Enable macros
   for this trusted workbook. Do not open a template in examples/excel.
4. Set Initial cash in the yellow cells B19:B23.
5. Click Update yourself to download initial prices and FX rates.
6. Enter trades in A27:F226, oldest first. Finish the row and wait about
   two seconds. Cash, holdings and charts calculate from local data.
   Save the workbook as usual.

CURRENT CASH at the top, B4:B8, automatically reflects Buy, Sell and
Exchange. Do not overwrite these formulas. INITIAL CASH is B19:B23.

Only YOU choose when to click Update for new market data. Opening Excel,
editing trades and automatic calculation do not request prices or FX.
There is no scheduled market download.

If RESULTS NOT CURRENT appears, read the reason in the status area.
Complete the row, correct its inputs, or choose Update if data is missing.
Previous results stay visible until a successful calculation.

Fallback: save and close Excel. Run 2_Update to download and calculate,
or 3_Recalculate to calculate using only cached data.

Keep the whole folder: a lone Excel file cannot run the Python functions.
Share the original ZIP; each person runs Setup and works independently.
After moving the folder, rerun Setup.

Instructions: README.md and docs/TUTORIAL.md.
File reference: docs/FILES.md.
Backups: local_data/backups. Log: local_data/last_update.log.
Native Mac Excel tested. Windows native Excel UI has not been tested;
automated setup and Python checks cover both operating systems.
