本地 Excel 投资组合工具

先完整解压这个 ZIP。Windows 使用 .cmd 文件，Mac 使用 .command 文件。

第一次使用：双击 1_Setup，等待“初始化完成”。程序会联网下载本地 Python 环境，不需要自己安装。然后打开新生成的 Portfolio.xlsx，填写初始资金及交易。

日常使用：修改 Portfolio.xlsx，保存并关闭 Excel；双击 2_Update；等待“更新完成”后重新打开 Excel。第一次更新需要下载历史行情和汇率，可能需要几分钟。

每个人下载一份、独立使用，交易和结果互不影响。要发给别人，请发原始 ZIP，不要发带有你个人交易的工作文件夹。

行情更新开关在 Dashboard 的 E5 和 E6：Yes 下载最新数据，No 使用本机已经下载的数据。第一次没有缓存时会先下载初始数据。

每次成功更新前，原 Excel 会备份到 local_data/backups，保留最近 5 份。更新失败时请查看窗口提示，修正后重试；详细日志在 local_data/last_update.log。

Mac 提示没有执行权限时，打开终端，输入 chmod +x 和一个空格，把两个 .command 文件拖入窗口后按回车，再双击运行。若系统限制打开，请按系统提示允许来自本下载来源的文件。

需要桌面 Microsoft Excel。第一次初始化和行情刷新需要网络。移动整个文件夹后，请重新运行 1_Setup。详细操作、字段位置和计算说明见 README.md。
