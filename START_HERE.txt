本地 Excel 投资组合工具 1.1 测试版

完整解压 ZIP。Windows 使用 .cmd，Mac 使用 .command。

第一次：双击 1_Setup，等待初始化完成。它只安装本地运行环境，不下载行情。然后打开 Portfolio.xlsm，允许这个文件运行宏，由你自己点击表内 Update 获取初始价格和汇率。

日常：你填写或修改交易，程序自动按本地已有数据计算持仓、现金和资产走势图，不请求行情 API。想获取新数据时，由你自己决定何时点击 Update。没有定时或打开文件时的自动下载。

状态区出现 RESULTS NOT CURRENT 时，原有结果尚未反映本次输入，请修正输入或自行点击 Update 补充行情。数据只覆盖已下载日期，不能把旧缓存当作最新行情。

按钮备用：保存并关闭 Excel 后，双击 2_Update 会联网获取行情并计算；3_Recalculate 只按缓存计算，不请求行情 API。自动计算不需要每天重复 Setup。

每人下载原始包、各自 Setup，各自独立使用。请分发整个原始 ZIP。只有一个 Excel 文件无法调用配套的 Python 程序。移动工具文件夹后需要重新 Setup。

测试状态：后台计算及数据隔离有自动测试，新宏已在 Mac Excel 中运行并创建按钮。Excel 内完整自动计算与结果导回流程、Windows 原生 Excel 界面仍需验证。外部入口可作为备用。

详细填写方法、升级和恢复说明见 README.md。备份在 local_data/backups，日志在 local_data/last_update.log。
