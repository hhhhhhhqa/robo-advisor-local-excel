# What each file does

Ordinary users only need to run Setup once, open Portfolio.xlsm, enter inputs and choose Update when needed. Keep the whole folder: its supporting files provide the Python functions used by Excel.

## Files you open or run

| File | Purpose | When to use it |
| --- | --- | --- |
| `START_HERE.txt` | Short first-run checklist | Read after extracting the ZIP |
| `README.md` | Main setup, usage, input and troubleshooting guide | Start here on GitHub |
| `docs/TUTORIAL.md` | Worked buy, sell and currency-exchange exercise | Learn the workflow and expected results |
| `docs/FILES.md` | This file reference | Identify an unfamiliar file |
| `CHANGELOG.md` | Changes by release | Check what an update includes |
| `VALIDATION.md` | What was actually tested and remaining limits | Check platform and feature coverage |
| `UPSTREAM.md` | Preserved upstream project reference | Research/development context; use README for this package |
| `1_Setup.command` | Mac one-time setup entry point | First use, or after moving/repairing the folder |
| `1_Setup.cmd` | Windows one-time setup entry point | Same purpose on Windows |
| `2_Update.command` | Mac external download and calculation entry point | A deliberate market refresh with Excel saved and closed |
| `2_Update.cmd` | Windows external download and calculation entry point | Same purpose on Windows |
| `3_Recalculate.command` | Mac cache-only calculation entry point | Offline recalculation with Excel closed |
| `3_Recalculate.cmd` | Windows cache-only calculation entry point | Same purpose on Windows |
| `Portfolio.xlsm` | Your working workbook, generated by Setup | Open this for daily use; contains your inputs and results |

The `.command` and `.cmd` files are alternatives for different operating systems, not separate steps to run on the same computer. Running Setup again does not reset an existing working workbook.

## Templates and configuration

| File | Purpose |
| --- | --- |
| `examples/excel/robo_advisor_dashboard_button.xlsm` | Fresh macro-enabled template copied by Setup. Includes the Update button, event-driven calculation and current/initial cash layout. No personal trades or cached market data. |
| `examples/excel/robo_advisor_dashboard.xlsx` | Legacy macro-free template retained for import compatibility and the upstream command-line workflow. Its initial-cash layout differs from the current local template. |
| `examples/excel/robo_advisor_dashboard_demo.xlsx` | Historical upstream preview with fictional transactions. It is not your working file, has no local Update-button integration, and does not provide current data. |
| `config/assets.json` | The 19 supported ETF symbols, names, regions, factor mappings and history start date. Preserve the configured symbols unless you are adapting the code and understand the data requirements. |
| `pyproject.toml` | Application version, Python requirement and package dependencies. Used by Setup. |
| `uv.lock` | Exact dependency resolution used for reproducible installation. |
| `.python-version` | Requested Python version for the local environment. |

Do not edit a template to maintain your own portfolio. Setup copies the template to Portfolio.xlsm so your working data remains separate.

## Files generated on your computer

These files are intentionally excluded from GitHub and the public release ZIP.

| Path | Purpose | Handling |
| --- | --- | --- |
| `local_data/market/etf_prices.parquet` | Downloaded ETF closing-price cache | Changed by your explicit Update |
| `local_data/market/fx_rates.parquet` | Downloaded FX cache | Changed by your explicit Update |
| `local_data/backups/` | Timestamped calculation-input backups; latest five automatic backups retained | Keep private; copy a backup to restore inputs |
| `local_data/last_update.log` | Local diagnostic log | Read when an operation fails |
| `local_data/update.lock` | Prevents two operations writing concurrently | A leftover file alone does not mean a process is still locked |
| `local_data/yfinance/` | Provider timezone/cookie caches created during downloads | Local implementation data; keep private |
| `local_data/button_input.xlsm`, `button_result.xlsx`, temporary staging folders | Compatibility paths and intermediate calculation files | Do not open or distribute as the working workbook |
| `.tools/` | Folder-local `uv` installer/runtime-management tool | Installed by Setup; keep with this installation |
| `.runtime/` | Managed Python installation and installer cache | Installed by Setup |
| `.venv/` | Python environment and dependencies used by Excel | Installed by Setup; rerun Setup after moving the folder |
| `__pycache__/`, `.pytest_cache/`, `*.egg-info/` | Python/developer caches | Generated automatically; not portfolio inputs |
| `~$Portfolio.xlsm` | Excel's temporary open-file marker | Managed by Excel; do not share |
| `Portfolio.xlsx` | Optional older working file kept during import | Keep as a backup if upgrading from the legacy format |

On Mac, Setup also installs `RoboAdvisorExcel_v2.applescript` under `~/Library/Application Scripts/com.microsoft.Excel/`. This helper lets Excel call the local launcher. Native Excel uses separate temporary input/result files in its own temporary directory during calculation. Neither location is a public upload destination.

## Application and integration code

| File | Purpose |
| --- | --- |
| `local_runner.py` | Setup/update/recalculation commands, folder locking, cache selection, backups and safe result staging. The automatic calculation path does not download market data. |
| `workbook_button.py` | Copy the macro template, import a legacy workbook, attach the VBA project and install the Mac helper. |
| `scripts/launch.sh` | Mac launcher; installs the folder-local environment during Setup and calls Python for each action. |
| `scripts/launch.ps1` | Windows equivalent of the launcher. |
| `excel_button/Module1.bas` | Reviewable VBA for the Update button, queued local calculations, importing results, chart/slider rebinding and status/error handling. |
| `excel_button/ThisWorkbook.cls` | Workbook events that detect input edits, refresh historical selection and cancel pending work on close. |
| `excel_button/RoboAdvisorExcel_v2.applescript` | Source of the Mac Excel-to-launcher bridge. |
| `src/robo_advisor/excel_frontend.py` | Read/validate workbook inputs, simulate Buy/Sell/Exchange, calculate daily history and produce dashboard results. |
| `src/robo_advisor/market_data.py` | Download/load ETF and FX snapshots, enforce completed-day and FX freshness rules, and answer date-specific price queries. |
| `src/robo_advisor/performance.py` | Daily portfolio return, annualized Sharpe and drawdown calculations. |
| `src/robo_advisor/excel_controls.py` | Add and bind the Excel date slider/form-control parts. |
| `src/robo_advisor/config.py` | Project paths and asset-configuration loading/validation. |
| `src/robo_advisor/__init__.py` | Python package entry marker. |

## Upstream research modules

These are retained for the separate upstream research pipeline. Ordinary local Excel use does not require running that pipeline or downloading factor data.

| File | Purpose |
| --- | --- |
| `scripts/build_data_pipeline.py` | Developer command to build the research dataset. |
| `src/robo_advisor/pipeline.py` | Coordinate price/factor loading, return construction, alignment and research output. |
| `src/robo_advisor/download_prices.py` | Research ETF-price download/normalization. |
| `src/robo_advisor/download_factors.py` | Kenneth French factor-data download/processing. |
| `src/robo_advisor/factors.py` | Factor transformations and research features. |
| `src/robo_advisor/returns.py` | Daily and monthly return construction. |
| `src/robo_advisor/alignment.py` | Align assets, factor dates and information availability. |
| `src/robo_advisor/validation.py` | Validate the research dataset. |
| `src/robo_advisor/utils.py` | Shared research/data utilities. |
| `data/raw/ff3/.gitkeep`, `data/raw/metadata/.gitkeep`, `data/final/.gitkeep` | Empty directory placeholders. Generated research datasets are not distributed. |

## Development, release and tests

| File | Purpose |
| --- | --- |
| `scripts/build_workbook.py` | Developer-only rebuild of embedded VBA and fresh-workbook layout while preserving native workbook parts. |
| `scripts/vba-builder/main.go` | Rebuild VBA source streams using the pinned OVBA library; Excel compiles for the recipient's Office version. |
| `scripts/vba-builder/go.mod`, `go.sum` | Pinned developer-only Go dependencies. No Go installation is needed by ordinary users. |
| `scripts/package_release.py` | Build a ZIP from tracked files; reject local/private data; preserve launcher permissions and Windows line endings; write a SHA-256 checksum. |
| `.github/workflows/test.yml` | macOS/Windows setup and automated Python checks on pushes and pull requests. |
| `.gitignore` | Exclude working portfolios, personal data, environments and generated files from Git. |
| `.gitattributes` | Preserve binary Excel files and operating-system-specific text line endings. |
| `tests/test_local_runner.py` | Independent copies, offline calculation, cash-layout migration, locks, backups and safe failures. |
| `tests/test_workbook_button.py` | Macro-source consistency, fresh template, legacy import, snapshot isolation and native workbook parts. |
| `tests/test_excel_frontend.py` | ETF trades, FX, input rules, daily history and monitoring. |
| `tests/test_prices.py` | Price-data handling. |
| `tests/test_returns.py` | Return construction. |
| `tests/test_factors.py` | Factor processing. |
| `tests/test_alignment.py` | Date/information alignment. |
| `tests/test_no_lookahead.py` | Prevent use of future information in research features. |
| `tests/test_pipeline.py` | End-to-end research-pipeline behavior. |

The release ZIP contains the program, templates, docs and tests, not a copy of the maintainer's installed environment or working portfolio. Older tags remain available for reproducibility; use the version linked in the main README for the current workflow.
